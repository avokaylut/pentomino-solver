# Пентамино: поиск с возвратом

Учебный проект по дискретной математике на **Wolfram Mathematica**. Задача — заполнить прямоугольное поле двенадцатью фигурами пентамино без пересечений и пустых клеток.

## Алгоритм

1. Найти первую свободную клетку поля.
2. Перебрать допустимые положения ещё не использованных фигур.
3. Проверить границы поля и отсутствие пересечений.
4. Проверить оставшиеся пустые области: площадь каждой должна быть кратна пяти.
5. Разместить фигуру или вернуться к предыдущему шагу, если продолжение невозможно.

В коде заданы 12 фигур и 63 варианта их ориентации. Выбор среди подходящих вариантов случайный; число шагов может отличаться между запусками. Программа сохраняет состояния поля для анимации.

## Файлы

- `pentomino.nb` — notebook с кодом и выбором размера поля.
- `pentomino.wl` — текстовая версия для просмотра исходного кода; по умолчанию поле 6 × 10.

## Запуск

Нужна Wolfram Mathematica. Исходная работа создана в версии 13.3.

Откройте `pentomino.nb` и выполняйте ячейки сверху вниз сочетанием **Shift + Enter**. В окне выбора размера введите:

| Число | Размер поля |
|---|---|
| 1 | 4 × 15 |
| 2 | 6 × 10 |
| 3 | 3 × 20 |
| 4 | 5 × 12 |

Последняя ячейка показывает анимацию размещения фигур и возвратов. Перед новым расчётом выполните ячейки с начала. В `pentomino.wl` размер задаётся строкой `{height, width} = {6, 10};`.

Поиск возвращает одно заполнение поля, а не все возможные решения. На сложных ветвях перебор может занимать длительное время, а сохранение всех промежуточных состояний — заметный объём памяти.
